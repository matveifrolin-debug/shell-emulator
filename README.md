# Эмулятор командной строки UNIX (вариант 18)

GUI-эмулятор оболочки ОС на Python + tkinter.

## Этап 1. REPL
- Заголовок окна: `Эмулятор - [user@host]` по данным реальной ОС.
- Раскрытие переменных окружения: `$HOME`, `${USERNAME}`.
  Неизвестная переменная заменяется пустой строкой.
- Команды-заглушки `ls`, `cd` выводят имя и аргументы.
- `exit` закрывает эмулятор.

## Этап 2. Конфигурация
| Параметр        | Описание                            |
|-----------------|-------------------------------------|
| `--vfs PATH`    | путь к CSV-файлу VFS                |
| `--script PATH` | путь к стартовому скрипту           |

- При запуске выводятся все параметры (`[debug]`).
- Стартовый скрипт выполняется построчно, ввод и вывод
  отображаются как в диалоге с пользователем.
- Ошибочные строки пропускаются, об ошибке сообщается
  в формате `файл:строка: описание`.
- Поддерживаются комментарии `#`.

## Этап 3. VFS
VFS загружается из CSV-файла и хранится только в памяти.

Формат CSV:
```
path,type,content
/docs,dir,
/docs/todo.txt,file,MS4gbHMK
```
| Столбец   | Значение                                         |
|-----------|--------------------------------------------------|
| `path`    | абсолютный путь; вложенность задаётся путём      |
| `type`    | `dir` (каталог) или `file` (файл)                |
| `content` | содержимое файла в base64 (у каталога пусто)     |

Недостающие родительские каталоги создаются автоматически.

Ошибки загрузки (файл не найден, неверный заголовок,
неизвестный тип, неверный base64, относительный путь,
дубликат) выводятся с номером строки CSV.

Служебная команда `vfs-info` выводит статистику и дерево VFS.

Примеры VFS в папке `vfs`:
| Файл          | Описание                          |
|---------------|-----------------------------------|
| `minimal.csv` | только корень                     |
| `several.csv` | несколько файлов                  |
| `deep.csv`    | 3+ уровня, двоичный файл          |
| `broken.csv`  | ошибка формата                    |

## Запуск
```
run.bat [--vfs PATH] [--script PATH]      # Windows
./run.sh [--vfs PATH] [--script PATH]     # Linux / Git Bash
```

## Тестовые скрипты (папка scripts)
| Скрипт                    | Что проверяет                   |
|---------------------------|---------------------------------|
| `test_no_params.bat`      | запуск без параметров           |
| `test_vfs.bat`            | только `--vfs`                  |
| `test_script.bat`         | только `--script`               |
| `test_all_params.bat`     | оба параметра, ошибочные строки |
| `test_exit.bat`           | `exit` в стартовом скрипте      |
| `test_missing_script.bat` | несуществующий скрипт           |
| `test_bad_param.bat`      | неизвестный параметр            |
| `test_vfs_minimal.bat`    | минимальная VFS                 |
| `test_vfs_several.bat`    | VFS с несколькими файлами       |
| `test_vfs_deep.bat`       | VFS с 3+ уровнями               |
| `test_vfs_not_found.bat`  | VFS не найдена                  |
| `test_vfs_broken.bat`     | VFS неверного формата           |
